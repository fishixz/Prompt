MIGRAÇÃO COMPLETA DO ONYX ONE PARA O CELULAR DO ROCHA ROLEPLAY

Você deverá trabalhar diretamente no projeto atual do celular do Rocha Roleplay.

A base visual que será utilizada para substituir o celular atual é o ONYX ONE, baseado no Sky Phone 0.3.5:

https://github.com/sky-systems/sky_phone/releases/download/0.3.5/sky_phone-0.3.5.zip

Leia TODAS as instruções antes de começar.

---

1. REGRA PRINCIPAL — NÃO RECRIE O CELULAR

Esta é a regra mais importante de todo o trabalho.

NÃO recrie o ONYX ONE do zero.

Não tente reproduzir visualmente o Sky Phone usando HTML/CSS novo.

Não crie uma interface "parecida".

Não faça uma versão simplificada.

Não faça uma cópia baseada em screenshots.

Não substitua seus componentes originais por componentes genéricos.

Você deverá utilizar a interface original do ONYX ONE/Sky Phone, trabalhando sobre os próprios arquivos, componentes, estilos, assets, animações e estrutura do projeto original.

O objetivo é pegar o ONYX ONE real e adaptá-lo para funcionar dentro da infraestrutura já existente do celular do Rocha Roleplay.

A aparência final deve continuar sendo a aparência original do ONYX ONE, salvo as alterações explicitamente solicitadas neste documento.

---

2. NÃO RECRIE O PROJETO ATUAL DO ROCHA

Da mesma maneira, NÃO recrie toda a estrutura do celular atual do Rocha.

Primeiro analise o projeto existente.

O celular atual já funciona dentro do APK do Rocha e já possui uma infraestrutura capaz de abrir interfaces desenvolvidas com tecnologias web, utilizando HTML, JavaScript, CSS, assets e demais recursos.

O celular antigo já abre normalmente dentro do APK.

Sua tarefa é fazer com que, no lugar da interface atual, seja aberta a interface do ONYX ONE.

Em outras palavras:

ANTES:

APK → abre celular atual do Rocha.

DEPOIS:

APK → abre ONYX ONE adaptado.

A integração deverá ocorrer dentro da infraestrutura existente.

Não transforme isso em outro aplicativo Android.

Não crie outro APK.

Não crie uma segunda aplicação separada.

Não faça o usuário sair de uma interface e entrar em outra.

O ONYX ONE deverá ocupar o lugar do celular atual.

8. FORMATO DOS NÚMEROS TELEFÔNICOS

O Sky Phone utiliza números maiores.

No Rocha Roleplay o sistema telefônico utiliza apenas:

6 dígitos.

Formato visual:

000-000

Exemplo:

"123-456"

A regra deve ser global.

Não altere apenas o teclado.

Revise:

- Telefone;
- Contatos;
- Mensagens;
- histórico de chamadas;
- busca;
- compartilhamento de contatos;
- perfil;
- Configurações;
- qualquer lugar onde número telefônico apareça.

O campo de discagem deve aceitar no máximo 6 dígitos numéricos.

Exemplo:

Usuário digitou:

"123456"

Ao tentar digitar outro número:

"1234567"

o sétimo dígito deverá ser simplesmente recusado.

Não permita mais de seis números.

O hífen é preferencialmente apenas formatação visual.

Internamente pode utilizar:

"123456"

Visualmente apresentar:

"123-456"

Não introduza espaços de agrupamento no padrão original de dez dígitos do Sky Phone.
