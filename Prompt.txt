ROCHASYSTEM — REESTRUTURAÇÃO E EVOLUÇÃO DO CELULAR

Continue trabalhando no projeto atual exatamente a partir do estado em que ele se encontra.

Este projeto faz parte do ecossistema do Rocha Roleplay e representa a interface do sistema de celular utilizado pelo servidor.

O objetivo deste prompt é trabalhar EXCLUSIVAMENTE na interface, experiência de usuário, navegação, componentes, estados visuais e preparação dos aplicativos do celular.

Não tente implementar neste momento a integração direta com a gamemode SA-MP, scriptfiles, bancos da gamemode ou qualquer outro sistema externo que ainda não tenha uma API definida.

A comunicação com o servidor será feita posteriormente através de uma API própria do RochaSystem.

---

REGRA PRINCIPAL

Antes de alterar qualquer coisa:

1. Analise completamente o projeto atual.
2. Entenda a arquitetura existente.
3. Identifique os componentes reutilizáveis.
4. Identifique os aplicativos já existentes.
5. Identifique como o celular abre e fecha.
6. Identifique como as páginas são navegadas.
7. Identifique como temas e idiomas funcionam atualmente.
8. Identifique quais dados atualmente são mockados.
9. Identifique quais sistemas já possuem alguma integração.
10. Não recrie o projeto do zero.
11. Não substitua sistemas funcionais por versões simplificadas.
12. Não remova funcionalidades existentes sem necessidade.
13. Não altere visualmente algo que já funciona corretamente sem motivo.
14. Não crie dados falsos para simular funcionalidades reais quando uma estrutura melhor puder ser preparada para futura integração.
15. Não implemente backend externo neste momento.
16. Não invente endpoints de uma API que ainda não foi fornecida.
17. Não invente dados provenientes da gamemode.
18. Quando uma informação depender do servidor, prepare a interface para recebê-la através de uma camada de serviço/API futuramente.
